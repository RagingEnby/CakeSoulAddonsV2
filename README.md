# CakeSoulAddonsV2
[CakeSoulAddons](https://chattriggers.com/modules/v/CakeSoulAddons) is an ANCIENT [ChatTriggers Module](https://chattriggers.com/) I made for people who collect [Cake Souls](https://hypixelskyblock.minecraft.wiki/w/Cake_Soul) in [Hypixel SkyBlock](https://hypixelskyblock.minecraft.wiki/) back in 2023.

At some point, I decided to give it another shot. Unfortunately, Hypixel began migrating SkyBlock to newer versions before I could do anything meaningful with this project. That being said, all features in this ChatTriggers module are actively being worked on in my [iTEM](https://github.com/TGWaffles/iTEM) Fabric port!
